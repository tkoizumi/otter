## VERDICT

* uv 0.5.9 refuses a configured index that differs from the lock's recorded
  registry (e2, e3, e5: exit 2) even when the artifact is byte-identical, and
  does not fold a trailing slash (e5); it does fold host case (e6). With no
  index configured it installs from the URL the lock records (the no-index
  capture above), so a mirror-cut lock needs no flag and a PyPI-locked project
  cannot be redirected without re-locking.
* otter refuses that pairing before anything is fetched, naming the lock, the
  index it records and the index configured, and its preflight checks the
  registries the lock records when nothing is configured.
* Every assertion above has a mutation that makes it go red; the route reaches
  uv's real argv in the tests and uv's real behavior in the UV section.
