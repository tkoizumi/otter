--- 4. What the dry run revealed about the daemon environment ---
daemon:    no otter.daemon.env; nothing daemon-wide to configure

The daemon env file is read from the *project* directory, not from the runtime
checkout. So OTTER_WORKERS=1 and the notification URL set in
otter/otter.daemon.env do NOT reach a deploy run from another directory. It must be
placed in the deployed project, or passed with --daemon-env.
