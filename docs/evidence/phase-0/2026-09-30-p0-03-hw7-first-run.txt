--- why the suite could not catch it, and what the fix must include ---
The selfcheck stops at the gate, so it never reaches the archive expansion. That is the coverage
gap the author disclosed and round 4 flagged; this run is its concrete cost.

So the fix is the path AND coverage for the layout contract: the archive shape (jobs nested under
jobs/, the data members under data/, otter.db at the root) is an interface between hot-backup.sh
and the mode assertions, and nothing tested it. A case asserting that every archive path the mode
reads actually resolves inside a real hot-backup.sh output would have caught this.
