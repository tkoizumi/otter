# Archive

Superseded plans, ledgers and historical work orders, kept in-tree as records.

These are **not instructions**. They describe what was intended at the time, not
what the runtime does now. Internal links may point at code that has since been
deleted, and nothing here is updated when behaviour changes. For what an
installed Otter does, see the product contracts listed in
[CONTRIBUTING.md](../../CONTRIBUTING.md#documentation); for what happens next,
see [v0.4.0-and-cloud-phase-b-plan.md](../v0.4.0-and-cloud-phase-b-plan.md).
